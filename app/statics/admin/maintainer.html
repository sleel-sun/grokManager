账号注册
通过内置 Account Maintainer 启动浏览器自动注册 xAI 账号，并把采集到的 SSO token 自动回写到账户池。
普通 GPT 账号批量注册
登记 ChatGPT/Codex 普通账号。可先保存邮箱/密码/mailToken 为待登录状态，也可直接保存 OpenAI OAuth access token / refresh token。
每行一个账号。格式：JSON 对象，或 email,password,mailToken[,alias,emailProvider,planType]。
如果只填写 access token，会保存为可用账号；如需 refresh_token/id_token/account_id，请使用上方 JSON 行。
自动注册会使用下方 xAI 注册配置中的临时邮箱域名、Worker 管理密码、注册数量和并发数；成功拿到 ChatGPT session token 时保存为可用账号，否则保存为待登录/待验证凭据。
GPT 图片账号注册
保存 ChatGPT 图片账号凭据或 access token，用于 gpt-image-1 / gpt-image-2。只有 access token 可立即用于生图；邮箱/密码/mailToken 会先保存为待登录状态。
没有 access token 时必须填写邮箱、密码和 mailToken；有 access token 时邮箱可选。
如果填写多行 token，会批量保存；同一组别名/邮箱元数据会应用到每个 token。
优先级高于上方单条邮箱表单。格式：JSON 对象，或 email,password,mailToken[,alias,emailProvider,isFree]。
注册任务
需要先准备临时邮箱 Worker。任务启动后会在后台运行，同一时间只允许一个注册任务。
只填域名，不要带 https://。对应 maintainer 配置里的 email.worker_domain。
多个域名用英文逗号分隔。
会保存到本机运行时配置文件；已保存后可留空沿用，不会在状态接口和日志尾部返回。
每个 worker 的注册轮数；总注册数 = workers × 此值。无上限，按账号池容量和上游配额自行控制。
同时起多少个浏览器子进程（1 为顺序运行）。workers × 注册数量 = 本次任务总注册数。无上限，但每个 worker 大约要 0.5-1GB 内存 + 1 个 Chromium 进程，请按机器实际容量调；运行后查看「实际并发 worker」状态卡 / orchestrator 日志确认 spawn 数。
自动未拿到 Turnstile 响应时，等待人工完成验证/提交的最长秒数；0 表示自动：真实图形桌面等 180 秒，Headless/Xvfb/无 DISPLAY 不等待。
无图形服务器建议配置外部 solver；关闭时只使用自动点击/Xvfb 路径。
保存到本机运行时配置；状态接口和日志不会回显。
